## 🙋‍♂️ About Me

### 📊 데이터 기반 문제 해결에 강점이 있습니다
정성적 사용자 피드백을 정량 데이터로 검증하고, 근본 원인을 분석해 개선합니다.  
CLIPZY에서 사용자 정답률 편차(33%~100%)를 **4분위 분석**하여 **AI Agent 3-Layer 파이프라인** 도입 근거를 도출했습니다.

### 🚀 처음 다루는 기술도 실전에 녹여내는 학습 실행력을 갖췄습니다
`WebSocket(STOMP)`, `LLM 프롬프트 엔지니어링`, `Redis 캐싱` 등 신규 기술을 학습하며 서비스에 적용했고,  
OpenAI 장애 3건을 겪고 **Self-Correction · Retry · Fallback**의 3중 안전장치를 직접 설계했습니다.

### 🤝 즉각적인 공유와 소통으로 협업합니다
API 명세 변경이나 이슈 발생 시 팀원에게 바로 공유하고,  
다른 팀원이 겪는 문제도 함께 원인을 분석해 해결책을 도출합니다.
